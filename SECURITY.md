# Security

## Reporting a vulnerability

Please don't open a public issue. Report it in private through GitHub: on the
repository's **Security** tab, choose **Report a vulnerability**.

Include what you found, how to reproduce it and which versions it affects. A
small reproduction helps more than anything else.

You'll get a reply within a week. If the report holds up, we fix it, publish
a release and credit you in the advisory unless you'd prefer we didn't.

## Supported versions

Fixes go into the latest release. Before 1.0, older versions get no patches.
