# @lunarhue/table-react

Headless tables for React, from [table](https://github.com/LunarHUE/table). React 18+ by default. On React 16.8 or 17, resolve with the `@lunarhue/react-legacy` condition.

This package exports only a placeholder for now. The API lands in a later release.

```sh
npm install @lunarhue/table-react
```
